# Digital Magnet Productions

A high-performance creative agency web platform featuring bespoke typography, 3D WebGL interactive shapes, GSAP micro-animations, and responsive editorial case studies.

## Technical Architecture & State Analysis

For a complete technical breakdown, situation report, architectural audit, and proposed engineering roadmap, refer to:

### Quick Start

```bash
# Install dependencies
npm install

# Start local server
npm start
```
Server runs on `http://localhost:3000`.
